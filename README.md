# Healthcare Prescription Safety & Patient Risk Intelligence Platform

## Overview

This project analyzes healthcare data to identify:

- High-risk patients

- Potential readmission risks

- Medication safety concerns

- Adverse drug events

The project combines electronic health records from the MIMIC-IV Demo dataset with adverse drug event data from the OpenFDA API.

## Data Sources

### MIMIC-IV Demo

Patient admission and diagnosis data.

### OpenFDA API

Drug adverse event reports.
